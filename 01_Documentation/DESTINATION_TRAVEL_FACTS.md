# Destination Travel Facts — original vs researched

Two sets of figures side by side so they can be compared before any page is changed:

- **Original** = exactly what each Destinations page says today (from `post_content`, Local backup).
- **Researched** = road driving distance Calais → town, checked July 2026 against
  route planners (ViaMichelin / Rome2Rio / distance calculators; typical driving
  route, not straight-line). Where sources disagreed, a representative mid-value
  is shown; "~" marks an approximate value where no single figure was clear.

**No pages have been edited** — this is a comparison sheet only.

Δ = researched − original (km). Airports/transfer times are the page's own text;
notes call out the ones worth changing.

### Method / caveats
- Road distances vary a little by chosen route (Belgium vs Luxembourg corridors);
  treat researched values as ±15 km. Only the larger gaps above are worth acting on.
- Transfer times were **not** re-timed here (they depend on live rail/road schedules);
  the airport column simply repeats the page. Berlin/Dresden airport notes are the
  exceptions worth fixing regardless of distance.
- Approximate ("~") values are where no single clean figure was returned and the
  number is inferred from neighbouring cities — verify those before publishing.
